# Servall Website

Servall is a comprehensive platform for two-wheeler maintenance, EV care, and genuine accessories. This website serves as the digital front for Servall Automotive Private Limited, providing information about their services, franchise opportunities, and a seamless service booking experience.

## Key Features

- **Service Booking**: Online portal for booking vehicle maintenance and repairs.
- **Service Range**: Information on general & periodic services, accidental repairs, engine repairs, and EV maintenance.
- **Genuine Spare Parts**: Catalog of genuine parts and smart accessories.
- **Franchise Modules**: Detailed information for potential franchise partners.
- **Workshop Locator**: Easy discovery of nearest Servall workshops using state and city filters.
- **Customer Focusing**: Meticulous care for vehicles and transparent billing.

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Libraries**:
  - [jQuery](https://jquery.com/) (v3.7.1)
  - [Swiper](https://swiperjs.com/) (v11) for interactive sliders
  - [Slick Carousel](https://kenwheeler.github.io/slick/) for carousels
- **Integrations**:
  - Google Analytics (G-2Z5K95081T)
  - Meta Pixel for conversion tracking
  - Tagembed for social media feeds

## Project Structure

- `index.html`: Main home page.
- `about-us.html`, `services.html`, `contact-us.html`: Core informational pages.
- `service-booking.html`: Online service booking portal.
- `own-franchise.html`: Franchise inquiry and information page.
- `css/`: Stylesheets including `style.css`, `responsive.css`, and `plugins.css`.
- `js/`: JavaScript files for interactive features and dynamic content.
- `images/`: Static image assets.

## How to Use

To view the website locally, simply open the `index.html` file in any modern web browser.
